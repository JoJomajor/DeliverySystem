# DeliverySystem
Тренировочный проект
Консольный симулятор диспетчера доставки, который контролирует процесс независимой курьерской организации по принципу C2C.
Учебный пет-проект: закрепление базы C# (события, делегаты, асинхронность, персистентность).

## Стек и запуск
- .NET 11, C# 15, внешних зависимостей нет
- Запуск: `dotnet run` из папки проекта

## Решения
- 2026-10-13: Person — один рекорд на роли отправителя и получателя.
  Причина: роль — это контекст использования, а не природа объекта;
  наследование ради ролей — антипаттерн. Альтернатива (классы Sender/Recipient) отклонена.

- 2026-10-14: appsettigns - json файл, хранящий в себе пути до различных данных проекта.

- 2026-10-14: LoginScreen - Объект реализующий логику экрана авторизации пользователя системы. Объект обращается к appsettings, 
  хранящий в себе пути к данным проекта. Были варианты использования дополнительные объекты такие как LoginScreenSettings для инициализации объекта, но отказано по причине полной изоляции логики от основного приложения.

- 2026-10-14: LoginScreen:LoadConfigData метод реализован таким образом, что изолирует в себе чтение пути из appsettings.json. И по этому путиизвлекает данные из бд пользователей системы.
